# Problem Statement

## Project Title
Engineer an Image Super-Resolution Framework for Enhancing Low-Quality Surveillance Footage.

## Problem
Surveillance cameras may produce low-quality footage due to limited resolution,
noise, compression, blur and poor lighting conditions.

These limitations can make visual inspection difficult.

## Proposed Solution
Develop a deep learning-based image super-resolution framework that attempts
to reconstruct high-resolution images from low-resolution inputs.

## Objectives
1. Study image super-resolution techniques.
2. Develop a preprocessing and degradation pipeline.
3. Implement CNN-based super-resolution.
4. Implement SRGAN and ESRGAN.
5. Evaluate reconstruction quality.
6. Process surveillance video frames.
7. Develop an image and video enhancement application.

## Expected Outcome
A modular prototype capable of processing low-resolution images and
surveillance-style videos and generating higher-resolution outputs.

## Limitations
Generated details may be artificial. Enhanced images must not be treated
as verified recovery of information missing from original footage.
